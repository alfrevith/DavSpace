# Beyond the Code (antes My Journey)

La línea de tiempo usa el ancla `#beyond-the-code` y conserva su composición y el progreso por
scroll. Sus tres estaciones ahora llevan a fotografía, dibujo y escritura. Los
proyectos siguen disponibles en su sección independiente.

Consulta [la guía de colecciones creativas](CREATIVE-WORLDS.md) para editar las
estaciones, agregar imágenes o PDFs, actualizar redes y regenerar los HTML.
